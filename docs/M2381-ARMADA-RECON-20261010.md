# armada-sheng 零刷机考据（2026-10-10 深夜，路线终决④）

> 仓 = code002-2/armada-sheng（浅克隆 `work/ref/armada-sheng`，本文行号/路径皆指克隆内）。
> 目标 = 移植⑤（换 r80+ 内核腿 + meizu 层）前把它的会话层/输入层/睡眠层读透，
> 并对照我们三堵墙（游戏内手柄 / 游戏内 QAM / menu→game 黑屏）逐一定位它的答案。
> 上游底座 = Terra（Fedora 系）+ OpenGamingCollective gamescope-session-plus；

## 0. 结论速览

1. **手柄进游戏的答案 = InputPlumber + deck-uhid**：所有物理输入被 InputPlumber
   （shadowblip，0.81.0）截获成 CompositeDevice，按用户选择伪装成四类目标之一
   （`deck-uhid`=Steam Deck / `xbox-series` / `xb360` / `ds5`），经 **uhid** 出
   Valve Deck 手柄（VID:PID = **28DE:12F0**）给 steam——steam 看到的是第一方
   Deck 手柄，steam input→Proton 注入走原生路径。udev 规则专门给 steam 组开
   deck-uhid hidraw 权限（`70-armada-inputplumber.rules`）。**这就是 r80 uhid
   腿在 armada 上的用途**；我们 steam 自建 uinput 虚拟手柄（event6）是另一条路，
   armada 路线更彻底（带 capability map/校准/overlay 截获开关）。
2. **Steam 启动身份件比我们多两个旗标**：`-gamepadui -steamos3 -steampal
   -steamdeck`（`usr/libexec/armada/launch-steam` + sessions.d/steam 的
   CLIENTCMD）——我们只传前两个。**且绝不给 steam 挂 WAYLAND_DISPLAY**（我们
   v7 黑屏路线被上游规避）：launcher 从 gamescope 启动应答拿
   `GAMESCOPE_WAYLAND_DISPLAY`，launch-steam 只把它软链成固定名
   `gamescope-primary`（gamescopectl/控制面用）。
3. **特性协商 env 一整排**（sessions.d/steam）：`STEAM_GAMESCOPE_{VRR,HDR,
   TEARING,FANCY_SCALING,DYNAMIC_FPSLIMITER,NIS,COLOR_MANAGED,VIRTUAL_WHITE}_
   SUPPORTED=1`、`STEAM_MULTIPLE_XWAYLANDS=1`、`GAMESCOPE_FALLBACK_APPID=0x41524d41`
   （hex "ARMA"，配 gamescope 补丁 0001 焦点回退）、`QT_IM_MODULE=steam`/`GTK_IM_
   MODULE=Steam`（OSK）、开机/关机 sentinel 等。ARM 客户端↔gamescope 的能力
   通道靠这些 env 建立——**我们的 v7 一件都没挂**。
4. **睡眠答案 = fake-suspend**（上游自证我们 ②b 的 FAIL）：脚本注释原文
   "Real suspend hangs this SoC"；`ARMADA_SUSPEND_MODE=s2idle|fake` 设备档案级
   可选；fake 模式换掉 systemd-suspend.service = 阻断 + Steam 熄屏 + 电源键
   （powerbuttond）唤醒，NetworkManager 打 `/etc/NetworkManager/ignore-sleep`
   补丁保 WiFi。真睡眠留内核线长跑。
5. **电源键答案 = powerbuttond**：evtest 监听 pwrkey，短/长按转发
   `steam://shortpowerpress|longpowerpress`（Steam 自带睡眠菜单），systemd-inhibit
   抢走 logind 的 handle-power-key——与我们 logind drop-in 方案殊途同归，
   但交互面（Steam 睡眠菜单）更 Deck。
6. **gamescope 本体重度魔改（27 个 armada 补丁）**：无 EDID 内屏合成 EDID/
   known-display profile、drm-lease-v1 全家、msm plane 逐 plane 色彩管线、
   libliftoff 多 primary stacking 修复、**原生 Wayland 窗口上报 Steam**、
   焦点回退 GAMESCOPE_FALLBACK_APPID、固定刷新率面板锚定 FPS limiter、
   `--force-vulkan-realtime`。会话 launcher 另有 9 补丁：设备 quirk 注入
   （`eval device-env`）、`ARMADA_GAMESCOPE_USE_ROTATION_SHADER=1` →
   `--force-composition-rotation`（**与我们同款 workaround**）、socket 超时
   5s→15s、drm-lease 副屏。
7. **会话切换双轨**：日常 = steamos-manager/`steamosctl`（switch-to-{desktop,
   game}-mode，用户 session bus 无需 root）；兜底 = `session-control` 直写
   `/etc/sddm.conf.d/zz-holo-autologin.conf`（zz- 命名压过 armada.conf，
   与我们 once-conf 同思路）；`armada-session-default.service` 每 boot 重置回
   gamemode（Before=display-manager）。Plasma 三形态 standalone/nested/bottom。
8. **Steam 客户端 = Valve 官方 ARM64，steamdeck_publicbeta 频道**，版本
   1788652215 + SteamRT 3c arm64（`packages/steam-bootstrap/BASE.env`，CDN
   client-update.steamstatic.com，`manifests/<version>` 可离线覆盖）——与我们
   现役同源 ⇒ **墙不在客户端 build，在会话集成**。Proton =
   proton-cachyos-11.0-arm64（CachyOS releases，`require_tool_appid` 行被 sed
   掉），x86 腿 = FEX（rootfs.fex-emu.gg Arch sqsh → /usr/share/guestos）。
9. **设备档案系统 = m2381 接入点**：`/usr/lib/armada/devices/*.conf` 按
   devicetree model 字符串匹配（`device-env` case 表），sm8550-xiaomi-sheng
   档案在案；**m2381 只需新增 `meizu-meizu20.conf`**（DT model 串 + 面板朝向
   right + 触屏/背光路径 + suspend 模式），案例照抄 ayn-odin-2.conf。
10. **考据未覆盖（留 A/B 刷机验证）**：sheng 实机（小米平板 6S Pro）游戏内 QAM
    / menu→game 往返是否全绿——README/补丁里没有显式的握手修法（无
    gamescope-control binding 相关补丁），⇒ 它的"手柄主场"名声可能主要来自
    InputPlumber 路径 + gamescope 魔改的隐性效果。**issue 区问询待发**（见 §4）。

                User=armada, Relogin=true)

     └─ /usr/bin/gamescope-session-plus steam          ← Terra RPM（上游 OGC）

        ├─ source /usr/share/gamescope-session-plus/sessions.d/steam

## 2. 输入栈（②d 手柄回归的 armada 答案）

- **InputPlumber 0.81.0**（`packages/inputplumber/`，BASE.env COMMIT 钉死，
  3 补丁：gamepad raw input / force-feedback reset / AYN Thor Lite），enable 于
  构建期（`40-vendor-system-files.sh:87`）。
- CompositeDevice 按 devicetree model 匹配 profile（`/usr/share/inputplumber/
  devices/*.yaml`，含 capability_maps）；m2381 需新增同款 yaml（或先不配，
  让 InputPlumber 通用模式接管 BT 手柄）。
- 目标选择：`ARMADA_IP_TARGETS=deck-uhid,xbox-series,xb360,ds5`（defaults.conf）
  → 用户选择落 `/etc/armada/controller.conf`（`controller-type` 脚本，system
  单元 `armada-controller-type.service` After/Requires inputplumber）。
- **deck-uhid 权限**：`70-armada-inputplumber.rules` 给 `hidraw*` 且
  `KERNELS=="0003:28DE:12F0.*"` 的节点 `GROUP="input" MODE="0660"`（注释：steam
  需要 deck-uhid hidraw 的组访问）。pmi8998_haptics uaccess 顺带在案（振动）。
- 运行时截获开关：`inputplumber-intercept status|overlay|gamepad|reset`
  （CompositeDevice0 InterceptMode：0 正常 / 2 overlay / 3 gamepad）。

## 3. 电源/睡眠/会话切换

- **powerbuttond**：evtest 抓 `*pwrkey*|*Power Button*`，短/长按（默认 1000ms）
  → `LD_LIBRARY_PATH=$STEAM_DIR steam -ifrunning "steam://shortpowerpress"`；
  SW_LID 同映射；`systemd-inhibit --what=handle-power-key:handle-suspend-key:
  handle-lid-switch --mode=block` 抢 logind。PartOf gamescope 会话。
- **fake-suspend**：挂成 systemd-suspend.service，阻断至电源键唤醒；
  经 `runuser -u armada` 对每个 `gamescope-N` socket 发 Steam 熄屏（8s 超时
  防卡 gamescope 连坐挂起）；NM ignore-sleep 补丁保 WiFi。设备档案
  `ARMADA_SUSPEND_MODE` 二选一（sheng 平板档案 = `mem`（其内核树 s2idle/deep
  可用），ODIN2 等默认 s2idle；hang 机型走 fake）。
- **切换**：运行时 `steamosctl switch-to-{game,desktop}-mode`（steamos-manager，
  hook 在 `usr/libexec/os-session-select` 接 steam 的"切换到桌面"）；
  steamos-manager 不可用/早期 boot 兜底 = `session-control` 写 SDDM conf；
  每 boot `armada-session-default.service` 重置回 gamemode。嵌套 Plasma 用
  `kwin_wayland --x11-display … --fullscreen --exit-with-session` +
  `DISABLE_GAMESCOPE_WSI=1`，systemd-run --user 单元活过 Steam 杀树。
